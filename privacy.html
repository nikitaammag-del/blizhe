Ближе к людям

Политика конфиденциальности

Последнее обновление: 23 сентября 2026 года

Коротко, если нет времени читать целиком: приложение «Ближе к людям» — личный некоммерческий проект одного человека. Веб-версия хранит ваш прогресс только в вашем браузере и никуда его не отправляет. Telegram-бот хранит ваш прогресс на сервере (Cloudflare), но виден только по вашему собственному запросу и удаляется командой /wipe. Рекламы, продажи данных и передачи третьим лицам нет.

1. Кто предоставляет сервис

«Ближе к людям» — некоммерческий проект, который ведёт один человек как личную инициативу, без регистрации юридического лица или ИП. Сайт: nikitaammag-del.github.io/blizhe.

2. Что и где хранится — веб-приложение (сайт)

  • Ваш прогресс, серия дней, заметки, ответы на вопросы вечерней рефлексии, настроение, избранное и настройки хранятся только в вашем браузере (технология localStorage), на вашем устройстве.
  • Эти данные не передаются на какой-либо сервер и не видны разработчику проекта.
  • Если вы очистите данные сайта в браузере или смените устройство, прогресс не сохранится, если вы заранее не воспользовались функцией экспорта в настройках приложения.
  • Сайт использует Cloudflare Web Analytics — счётчик посещений без файлов cookie, без отслеживания конкретного человека между сайтами. Собираются только обезличенные, агрегированные данные: количество посещений, приблизительная страна, тип устройства, адрес открытой страницы. Подробнее: cloudflare.com/web-analytics.
  • Ежедневное содержимое (уроки, новости, цитаты и другие материалы) сайт получает из открытого общедоступного файла на GitHub — эта загрузка не содержит и не передаёт никаких ваших личных данных.

3. Что и где хранится — Telegram-бот

  • Если вы пользуетесь ботом, для его работы обрабатывается: идентификатор вашего чата в Telegram (chat id), ваш прогресс по программе, тексты заметок и ответов, которые вы сами вводите, отметки настроения.
  • Эти данные хранятся на сервере Cloudflare (хранилище Workers KV), в инфраструктуре, которую использует бот, — не «в вашем телефоне».
  • Доступ к этим данным технически имеет только сам бот (автоматически) и владелец проекта через панель управления Cloudflare — в обычной работе он не просматривает содержимое чужих записей вручную.
  • Данные хранятся до тех пор, пока вы не удалите их сами командой /wipe в боте — это удаляет всю вашу историю без возможности восстановления.
  • Число участников бота ограничено (не более 30 одновременно), это ограничение технического характера, а не связанное с обработкой данных.
  • Бот не передаёт ваши данные в GigaChat или другие внешние системы — нейросеть используется только для подготовки общего, одинакового для всех ежедневного содержимого, без ваших личных данных.

4. Кому передаются данные

Данные не продаются и не передаются рекламодателям. Технически данные проходят через инфраструктуру следующих поставщиков услуг, необходимую для работы сервиса:

  • GitHub Pages — хостинг сайта;
  • Cloudflare — хостинг Telegram-бота и хранилище его данных, счётчик посещений сайта;
  • Telegram — доставка сообщений бота.

У каждого из этих поставщиков есть собственная политика конфиденциальности, которая тоже применяется при использовании их инфраструктуры.

5. Возрастные ограничения

Материалы приложения (новости, юмор) рассчитаны на аудиторию 16 лет и старше. Сервис не предназначен для детей младше этого возраста.

6. Ваши права

  • Веб-версия: вы полностью контролируете свои данные — они у вас на устройстве. Экспорт и очистка доступны в разделе «Настройки».
  • Бот: команда /export присылает файл со всеми вашими данными, команда /wipe удаляет их безвозвратно.
  • Вы можете в любой момент прекратить использование сайта или бота без каких-либо последствий.

7. Характер сервиса

Приложение — образовательный и развлекательный инструмент для самостоятельной практики общения. Оно не является психологической, медицинской или юридической консультацией и не заменяет обращение к специалисту. Часть материалов (уроки, переводы, разбор промптов) создаётся автоматически с использованием нейросети и может содержать неточности.

8. Изменения этой политики

Текст может обновляться по мере развития проекта. Дата последнего изменения указана в начале страницы.
