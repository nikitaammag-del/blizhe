# Ближе к людям — этап 1

**Говори. Узнавай. Расти.** Самостоятельное развитие коммуникации.

## Файлы
| Файл | За что отвечает |
|---|---|
| `index.html` | Каркас, стили (тёмная/светлая тема, адаптив, печать) |
| `app.js` | Вся логика: онбординг, разделы, API, прогресс, избранное, поиск, экспорт |
| `data.js` | Локальная база: цитаты, юмор, промпты, слова, книги, фильмы, треки, архив событий |
| `service-worker.js` | Офлайн: оболочка из кэша, API с таймаутом 8 с и запасным кэшем |
| `manifest.json` + `icons/` | Установка на телефон (PWA) |

## Запуск локально
Сервис-воркер не работает при открытии файла двойным кликом (`file://`). Запустите сервер:
```
cd gd
python3 -m http.server 8080
```
Откройте http://localhost:8080 (на localhost PWA и офлайн работают).

## Публикация (нужен https)
- **GitHub Pages:** загрузите папку в репозиторий → Settings → Pages → Branch `main` / root.
- **Netlify:** перетащите папку `gd` на https://app.netlify.com/drop
- **Vercel:** `npx vercel` в папке `gd` (или импорт репозитория).

## Установка на телефон
- **Android/Chrome:** меню ⋮ → «Установить приложение».
- **iPhone/Safari:** «Поделиться» → «На экран Домой».

## Источники данных и что делать при сбое
| Источник | Что даёт | Если не отвечает |
|---|---|---|
| ru.wikipedia.org REST «onthisday» | События дня | Снимок за этот день → архив из `data.js` |
| api.rss2json.com (RSS N+1, Naked Science) | Новости | Снимок → «Сегодня нет свежих данных» + кнопка «Обновить» |
| `data.js` | Цитаты, юмор, промпты, слова и т. д. | Локально, сети не требует |

Если rss2json упрётся в лимит бесплатного тарифа — замените в `app.js` массив `FEEDS` или поставьте свой прокси.
Ссылки MAX-бота, донаты и партнёрские ID — в объекте `CFG` в начале `app.js`.

# Ежедневное обновление контента

Приложение само по интернету не «ходит». Каждый день сборщик `tools/build-daily.mjs` (GitHub Actions, бесплатно) собирает подборку в `daily.json`,
а приложение забирает её при открытии и кэширует для офлайна. Нет подборки — работает запасная база из `data.js`.

## Включение (один раз, ~5 минут)
1. Залейте **содержимое папки `gd`** в корень репозитория GitHub (чтобы `index.html`, `tools/`, `.github/` лежали в корне).
2. Settings → Actions → General → Workflow permissions → **Read and write permissions**.
3. (Необязательно) Settings → Secrets and variables → Actions → New secret:
   - `GIGACHAT_AUTH_KEY` — «Ключ авторизации» из кабинета GigaChat: включает шутки нейросети и перевод промптов на русский (запасной вариант — `ANTHROPIC_API_KEY`);
   - `TMDB_API_KEY` — включает фильмы с рейтингом (бесплатный ключ на themoviedb.org).
4. Вкладка Actions → «Ежедневная подборка» → **Run workflow** — проверить вручную. Дальше запускается сам каждый день в 05:30 МСК.
5. В Настройки приложения → «Источники данных» видно дату подборки и сколько источников ответило.

## Откуда что берётся и как считается рейтинг
| Раздел | Источник | Рейтинг («лучшее по своему рейтингу») |
|---|---|---|
| Цитаты | Викицитатник (ru), ~50 авторов по ротации | есть указанный источник +3, длина 40–200 +2, не из «Приписываемых» +1. Без источника → «приписывается» |
| Новости | 10 лент: N+1, Naked Science, Элементы, Хабр, Nature, Science, BBC Science, Ars Technica, Guardian Culture, BBC Sport | вес источника + свежесть (до 72 ч) + 1,5 за каждое совпадение темы в другом издании; не больше 2 из одного источника |
| Промпты | Awesome ChatGPT Prompts (CC0) | роль +2, длина 200–900 +2, формат/ограничения до +3 |
| Слово дня | Викисловарь (ru), список редких слов в `WORDS` | значение и этимология берутся из статьи |
| Книги | Open Library | средняя оценка × ln(1 + число оценок), минимум 5 оценок |
| Фильмы | TMDB (нужен ключ) | оценка × ln(1 + число голосов) |
| Юмор | шутки GigaChat (нужен ключ), подпись «Шутка нейросети» | 7 критериев + правила длины (≤6 предложений) + стоп-слова + без повторов за 30 дней |

Что изменилось в правилах: цитаты, факты, слова, книги и фильмы **никогда не пишет нейросеть**, только источники. Формулы можно менять в `tools/build-daily.mjs`.

## Что сборщик сознательно не делает
- **Не копирует анекдоты и статьи** с anekdot.ru, из журналов и каталогов: это чужие тексты под авторским правом, а у anekdot.ru нет открытого API.
  Из лент берутся только заголовок, короткий анонс и ссылка на оригинал.
- **Не проверяет, смешно ли.** Юмор проходит фильтры, но живой смех оценить нельзя.
- Треки остаются в локальной базе: у открытых каталогов музыки нет надёжного рейтинга без ключей.

## Проверено / не проверено
- Проверено: парсеры (Викицитатник, RSS, CSV, Викисловарь) на тестовых данных; живой запрос к каталогу промптов; сборка не падает при отказе источников; приложение показывает `daily.json` и откатывается на локальную базу.
- **Не проверено вживую:** запросы к Викицитатнику, Викисловарю, RSS-лентам и Open Library (в моей песочнице они закрыты). URL лент могут устареть — при первом запуске смотрите `sources` в `daily.json`, нерабочие ленты правьте в `FEEDS`.

## GigaChat: что нужно знать
- Ключ вставляйте **только** в GitHub: Settings → Secrets and variables → Actions → New repository secret → имя `GIGACHAT_AUTH_KEY`. Не пишите его в чат, в код и в файлы репозитория (репозиторий публичный).
- Берётся «Ключ авторизации» (Authorization key) из личного кабинета GigaChat API, а не «Client Secret». Тариф по умолчанию `GIGACHAT_API_PERS` (для физлиц); для другого задайте переменную `GIGACHAT_SCOPE`.
- Сервер Сбера подписан сертификатом Минцифры. Workflow скачивает его сам (шаг «Сертификат Минцифры»). Если в Actions этот шаг падает с ошибкой 404, возьмите актуальную ссылку на «Корневой сертификат Минцифры» на gosuslugi.ru/crt и подставьте в `daily.yml`.
- **Не проверено вживую:** соединение GitHub-роботов (серверы вне России) с GigaChat. Логика проверена на имитации ответов. Если в `daily.json` в поле `sources` будет `humor → fail`, сообщение об ошибке подскажет причину.
- GigaChat может невольно пересказать известный анекдот, поэтому такие шутки подписаны «Шутка нейросети», а не «Оригинал».
