# Памятка: как запустить «Ближе к людям» бесплатно

Идея: сайт-«киоск» на GitHub Pages + «робот-почтальон» (GitHub Actions), который каждое утро кладёт свежий выпуск.

## Один раз
1. Аккаунт на github.com (бесплатно).
2. New repository → имя `blizhe` → **Public** → Create.
3. «uploading an existing file» → перетащите СОДЕРЖИМОЕ папки `gd` (включая `icons`, `tools`, `.github`) → Commit.
   Если папка `.github` не загрузилась перетаскиванием: Add file → Create new file → имя `.github/workflows/daily.yml` → вставьте текст из файла.
4. Settings → Pages → Source: «Deploy from a branch» → `main` / `/ (root)` → Save. Через 1–2 минуты появится адрес `https://ЛОГИН.github.io/blizhe/`.
5. Settings → Actions → General → Workflow permissions → **Read and write permissions** → Save.
6. Вкладка Actions → «Ежедневная подборка» → **Run workflow**. Зелёная галочка = первый выпуск готов.

## Телефон
- Android/Chrome: меню ⋮ → «Установить приложение».
- iPhone/Safari: «Поделиться» → «На экран Домой».

## Каждый день
Робот сам запускается в 05:30 МСК. Проверка: откройте `ВАШ_АДРЕС/daily.json` и посмотрите `date`.
Раз в месяц заглядывайте в Actions: если GitHub отключил расписание из-за неактивности — нажмите Enable.

## Не обязательно (ключи)
- `GIGACHAT_AUTH_KEY` — ваш ключ GigaChat: свежие шутки нейросети и перевод промптов на русский.
- `TMDB_API_KEY` (бесплатный) — фильмы с рейтингом.
Добавляются ТОЛЬКО тут: Settings → Secrets and variables → Actions → New repository secret. Никому не показывайте ключ и не вставляйте его в чат или в файлы.

## Проверка на компьютере до публикации
В папке откройте терминал: `python -m http.server 8080` → http://localhost:8080
